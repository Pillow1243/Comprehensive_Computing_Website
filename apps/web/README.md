# Client PWA

`apps/web/` is the client-first, zero-build app. It runs directly from a static server and remains the authoritative UI/solver experience; the root Next.js 16 project creates a static-export shell and copies this directory to ignored build output `public/app/`.

Run directly:

```bash
python3 -m http.server 8080 --directory apps/web
# http://localhost:8080
```

`registry.js` and `phase1-formulas.js` contain trusted formula functions; `engine.js` is the safe expression/unit engine; `plot.js` draws charts; `api.js` handles optional server-only calls. `runtime-config.js` is generated by the Pages build with the public `NEXT_PUBLIC_API_URL` value (blank by default). No API credential belongs in this configuration.
