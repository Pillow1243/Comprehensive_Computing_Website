# Wireframe متنی و جریان کاربر

## صفحه اصلی
```
┌ Topbar: لوگو | جستجوی سراسری | تم | زبان | نصب PWA ┐
├ Sidebar (دسکتاپ) / Drawer (موبایل): ابزارها + درخت دسته‌بندی
└ Main: Hero (آمار: ۱۵۵ فرمول فعال، ۲۹ بخش) + چیپ‌های پرکاربرد
        Grid کارت فرمول‌ها (۱ ستون موبایل → ۵ ستون در ۱۹۲۰px+)
```
جریان: جستجو (debounce ۲۰۰ms) یا انتخاب دسته → کلیک کارت → صفحه فرمول با پارامترها در URL (`#/formula/{id}?a=3&b=4`) → بازگشت/اشتراک همان وضعیت را باز می‌کند.

## صفحه فرمول
```
← بازگشت            [☆ نشان‌کردن] [🔗 اشتراک] [🖨 PDF] [TeX]
دسته ← … • نسخه • ✔ تست‌شده
H1 نام فرمول — توضیح — جعبه LaTeX
┌ ورودی‌ها (واحد قابل انتخاب) ┐ ┌ نتیجه (جدول) + حل گام‌به‌گام (شماره‌دار) ┐
└ رسم پویا (Canvas، بازرسم هنگام تایپ) ┘
مثال‌ها و تست‌های خودکار اعلام‌شده فرمول
```
حالت‌های خطا کنار نتیجه (مثلث ناممکن، a=0 در درجه‌دو، غلظت منفی) با پیام فارسی/انگلیسی نمایش داده می‌شود.
